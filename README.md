### 🌟 Featured Project
#### 🛡️ [CommanderX: Autonomous DevOps Incident Commander](https://github.com/praveshhh/coral-DEVOps-AI-Agent)
An autonomous, secure DevOps agent built for the **Coral Hackathon** that unifies incident diagnosis and telemetry correlation across multiple cloud platforms.
*   **Unified Querying**: Leverages Coral to run federated SQL queries over Datadog, GitHub, and a custom-built Vercel community source.
*   **Stateful Intelligence**: Multi-agent design backed by concurrent, thread-safe WAL-enabled SQLite session states.
*   **Pure Security**: Implements cryptographically secured handshake tokens protecting system-level execution endpoints.
